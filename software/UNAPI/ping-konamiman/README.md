# Konamiman's PING 1.1 (original)

Unmodified copy of Konamiman's "Ping for the TCP/IP UNAPI 1.1" (2/2014), kept
as the reference for `Client/src/ping.asm`, which is derived from it.

- `ping.asm`  - source, from https://github.com/Konamiman/MSX (SRC/NETWORK/ping.asm)
- `ping.com`  - binary, from https://www.konamiman.com/msx/networking/ping.com
              (sha1 80232774f6e05cd5873cd9d8be9da4cd9a3e9a78)
- `LICENSE.txt` - the repository license (MIT for software), (c) 2014 Nestor Soriano Vilchez

It sends one echo request and then waits for ENTER for each additional one.
